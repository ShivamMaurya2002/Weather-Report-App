**Weather Report App** is a clean, elegant, and mobile-friendly weather dashboard that provides real-time temperature, humidity, and wind data for any city using the **OpenWeatherMap API**. Built using **HTML, CSS, and JavaScript**, it emphasizes simplicity, speed, and responsiveness.

---

<h2 align="center">🌟 Key Features</h2>

<table align="center">
  <tr><td>📍</td><td><strong>City-Based Weather Lookup:</strong> Enter any city name to get current weather information instantly.</td></tr>
  <tr><td>🌐</td><td><strong>Real-Time API:</strong> Fetches live data using <code>OpenWeatherMap API</code>.</td></tr>
  <tr><td>🎨</td><td><strong>Responsive Design:</strong> Works seamlessly across mobile, tablet, and desktop devices.</td></tr>
  <tr><td>🌈</td><td><strong>Dynamic UI:</strong> Displays weather-specific icons and background changes (optional).</td></tr>
  <tr><td>⚡</td><td><strong>Lightweight:</strong> Fast loading and clean UI/UX.</td></tr>
</table>

### 🔐 API Integration

- **Provider**: [OpenWeatherMap API](https://openweathermap.org/api)
- **Required**: API key (free to register)
- **Usage**:
  - City input is used to fetch current weather data
  - Parsed and displayed using Fetch API in JavaScript
